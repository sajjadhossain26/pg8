# SkillSphere – Online Learning Platform

SkillSphere is a modern online learning platform where users can explore skill-based courses, view popular and trending programs, authenticate with email/password or Google, and manage their profile.

## Live URL
Add your deployed Vercel URL here.

## Key Features
- Responsive Navbar and Footer
- Home page with hero, popular courses, learning tips, top instructors, and trending courses
- All Courses page with search by course title
- Protected course details route
- Login, Register, Google login using Better Auth
- My Profile page and update profile information page
- Toast notifications
- Loader while fetching/searching data
- Custom not-found page
- Environment variable based configuration

## NPM Packages Used
- Next.js
- React
- Tailwind CSS
- DaisyUI
- Better Auth
- Framer Motion
- Sonner
- Lucide React

## Environment Variables
Create `.env.local` from `.env.example`.

## Run Locally
